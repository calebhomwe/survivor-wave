# Kingdom Survivor Clash — Backlog v2: Upgradables & Visual Improvements (2026-09-28)

v1.3.2 ships one self-contained HTML file: 6 heroes, 16 weapons + 16 EVOs, 10 passives, 11 BTD-style tower lines with 3 paths × 2 tiers and T3→T5 merges, 6 field stations, a 7-building Kingdom meta, 9 biomes across 17 chapters, and a 7-boss funny-boss gauntlet layered over the native Hornet Queen / Titan Boa.
This list is the next body of work: every item below was proposed by a code reader or the screenshot audit and then verified against the live file (line anchors are from v1.3.2; re-grep before editing, the file shifts).
Hard rules: the game stays ONE file with ZERO runtime network requests; `docs/CONTENT_GUIDE.md` is mandatory (engineering, military, medical, nature and technology framing only — no occult, ritual or magic framing anywhere, kingdom place names are fine); append-don't-reorder every shared table (`TD`, `PATHS`, `HEROES`, `WEAPONS`, `PASSIVES`, `META`, `THEMES`, `FAM`, `ELITE_AFFIXES`, `ACHIEVE_DEFS`, Kingdom `B`/`ORDER`); legacy save keys (`KSC_ALTARS`, `altarCost`, `player.relic`, …) stay private and never appear on screen.
Gate for every commit: `node tools/test-ui-regressions.cjs` and `python tools/smoke.py` both pass, and every new drawing is inspected in the browser (keyword guards do not certify visuals).
Item format: `**Uxxx/Vxxx [TAG] Title** — description with concrete numbers. Why. Effort S/M/L · Priority P1/P2/P3 · Anchors. Done: acceptance criterion.` Commit message `Uxxx: short title` / `Vxxx: short title`.
